# Plan de idiomas

App instalable con el plan diario de árabe, alemán, inglés y francés.

**Abrir la app:** <https://hogeraxel-cmd.github.io/plan-de-idiomas/>

- Cada idioma avanza lección por lección: la siguiente se desbloquea al completar la pendiente, y nada se salta.
- La pantalla principal muestra lo pendiente de días anteriores, el plan de hoy y lo que hiciste cada día.
- Carta Gantt de dos semanas, resumen semanal y recordatorio diario en el calendario del celular.
- Funciona sin conexión y se sincroniza entre PC y celular con Firebase.
